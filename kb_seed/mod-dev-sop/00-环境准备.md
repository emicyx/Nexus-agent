# SOP 00 · 环境准备与基线检查

> 目标：确认开发所需的游戏目录、游戏版本与参考资源就绪；按需安装 Rust 工具链。
> 适用：所有 Mod 项目的起点，做一次即可。
> 源文档：[getting-started](../TeamfightManager2Mod/docs/getting-started.md) ·
> [workshop-upload](../TeamfightManager2Mod/docs/workshop-upload.md) ·
> [stable-native-mods](../TeamfightManager2Mod/docs/stable-native-mods.md)

---

## 1. 你需要什么

| 项 | 数据/美术 Mod | 原生 Rust Mod | 说明 |
|---|---|---|---|
| Teamfight Manager 2 游戏本体 | ✅ | ✅ | 打包版或开发 checkout 均可 |
| `TFM2ModUploader.exe`（游戏自带） | ✅（发布时） | ✅（发布时） | 位于游戏文件夹 |
| Rust 工具链（`cargo` + `rustc`） | ❌ | ✅ | stable/nightly 均可，无版本钉死 |
| Aseprite（做动画时） | 可选 | 可选 | 可用 PNG + JSON 手写精灵表替代 |
| Mod SDK | ❌ | ✅（随游戏分发） | stable SDK：`mod-sdk-stable/` |

**数据/美术 Mod（英雄 JSON、图标、文本、覆盖、立绘包）完全不需要 SDK 和 Rust。**

## 2. 定位关键目录

### 2.1 游戏目录与 mods 目录

- 打包版：`mods/` 在**游戏可执行文件旁边**；没有就手工创建。
- 开发 checkout：用仓库自带的 `mods/` 文件夹。

```text
游戏目录/
  TeamfightManager2.exe
  TFM2ModUploader.exe
  steam_api64.dll
  bundle.game_data          ← 打包版的基础资源
  mods/                     ← 所有本地 mod 放这里
  mod-sdk-stable/           ← stable 原生 SDK（做原生 mod 才需要）
```

### 2.2 确认游戏版本

启动游戏，看**标题画面右下角**。记下版本号（如 `0.5.4`）——
后面写 `mod.mod_info` 的 `base` 依赖、选 SDK 版本都以此为准（见 SOP 01）。

### 2.3 stable SDK 位置（仅原生 mod 需要）

SDK 随游戏在**所有平台**分发：

| 平台 | 位置 |
|---|---|
| Windows | 游戏目录下 `mod-sdk-stable/`（在 `TFM2ModUploader.exe` 旁边） |
| Linux | 游戏可执行文件旁 `mod-sdk-stable/` |
| macOS | `TeamfightManager2.app/Contents/MacOS/mod-sdk-stable/` |

内容：

```text
mod-sdk-stable/
  mod-api-stable/    ← API crate（纯 Rust 源码，零依赖，全平台通用）
  template/          ← 可直接构建的 mod 模板工程
  README.txt
```

> 旧版 `mod-sdk/`（classic 路径）已弃用：仅支持到游戏 0.5，0.6 起不再分发。
> 新项目不要用它，存量迁移见 SOP 12。

## 3. 解包基础游戏资源（强烈建议做一次）

制作任何内容前，先解包基础资源作为**只读参考**——查基础英雄数值量级、
i18n 键名、精灵图标签、效果 JSON 写法都靠它。

### 操作步骤

1. 确保 Steam 已运行并登录。
2. 进入游戏文件夹，运行 `TFM2ModUploader.exe`。
3. 确认 `bundle.game_data` 与上传器同目录（默认就是）。
4. 点击 **Unpack Base Bundle**。
5. 完成后生成：

```text
mods/base_unpacked/
```

### 使用规则

- 解包结果与游戏基础资源同布局，例如打包内 `asset/base/text/ui`
  对应 `mods/base_unpacked/text/ui.i18n`。
- **只读参考**：不要把 `base_unpacked` 当作你的 mod 源码编辑，
  再次解包会直接覆盖该文件夹。
- 想改基础资产 → 用 [SOP 06](06-资产覆盖与合并.md) 的覆盖机制，
  把要改的内容放进**你自己的 mod 文件夹**。

## 4. 安装 Rust 工具链（仅原生 mod）

1. 从 <https://rustup.rs> 安装 rustup，默认 stable 工具链即可。
2. 验证：

```bash
cargo --version
rustc --version
```

3. 无需钉死特定版本（这是 stable API 相对 classic 的优势之一），
   也无需任何 SDK 依赖下载。

可选：`rand` 等第三方 crate 需要联网拉取，或预先填充 Cargo 缓存。

## 5. 基线检查清单

开始写 mod 前，逐项确认：

- [ ] 已知当前游戏版本（标题画面右下角）
- [ ] 已找到/创建 `mods/` 目录
- [ ] 已解包 `mods/base_unpacked/` 供参考（建议）
- [ ] （原生 mod）`mod-sdk-stable/` 存在且 `cargo`/`rustc` 可运行
- [ ] （发布）Steam 已登录到你想持有创意工坊物品的账号
